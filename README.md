# 학교 식물 탐사대 — 사진으로 찾고, 교과서와 잇는 식물 탐구 웹앱

카메라로 식물을 찍고 → (AI가 후보를 제안하면) → **국립수목원 공공데이터**로 공식 정보를 확인하고 → **2022 개정 교육과정 성취기준**과 연결된 활동을 하며 → 관찰 기록을 도감 카드로 남기는 초등 과학 탐구 웹앱.

- **휴대폰·태블릿**: 기본 카메라 앱으로 찍기 / 앨범에서 고르기 / 📋 붙여넣기 버튼 · 홈 화면에 추가하면 앱처럼 열림
- **컴퓨터**: 웹캠 창으로 찍기 / 사진 파일 고르기 / 끌어다 놓기 / **Ctrl+V(⌘+V)로 캡처한 사진 바로 붙여넣기**(패들렛처럼) · 넓은 화면 배치
- **사진 최대 3장**(전체·잎·꽃이나 열매)을 AI가 함께 보고 판단 → 이름을 몰라도 사진으로 알아보는 것이 주된 길
- **쓰는 사람마다 자기 키**: 공공데이터포털 키 + AI 키(제미나이·클로드·GPT 중 하나)를 각자 설정 화면에 넣으면 연동. 서버는 키를 저장하지 않음
- **학년 눈높이**: 국립수목원 원문을 항목마다 1~2 / 3~4 / 5~6학년 말로 풀이 + 낱말 풀이 (원문은 그대로 함께 표시)
- **학생 보기 / 선생님 보기**: 학생에게는 "우리 교과서에 이런 내용이 나와요"(학생 말), 선생님에게는 성취기준 원문·해설
- **관찰 낱말 그림 도움말**: 잎 모양·잎맥·줄기 선택지마다 그림, 마우스를 올리면 큰 그림+설명, '그림으로 알아보기' 창
- **관찰 그림**: 그림판(펜·지우개·글자·되돌리기·내 사진 위에 그리기) 또는 종이 그림 사진 올리기, 그림마다 설명 → 도감 카드에 저장
- **👩‍🏫 선생님 모드**(머리글 오른쪽 위 버튼): 키 저장 → 학년 → 학급 QR 3단계, 칠판·TV에 QR 크게 띄우기
- **국립수목원 도감에 없는 식물**: AI가 알려 준 다른 이름으로 도감을 한 번 더 찾아보고, 그래도 없으면 "국립수목원 식물도감에 정식으로 등록되어 있지 않아요"라고 알린 뒤 AI 정보를 '공식 정보 아님'으로 표시해 보여 줌
- **🎯 해 볼 활동**: 교과서 연결마다 초록 활동 상자(번호 단계·쓰는 칸·적으면 ✅), 위에 '활동 n개 중 m개 적었어요' 진행 막대
- AI(제미나이)는 **후보를 제안**하는 도구, 국립수목원 API는 **공식 정보를 확인**하는 도구, 교육과정 연결은 **정해진 규칙**(AI 아님)

## 1. 다른 사람이 쓰는 방법 (키 연동 구조)

앱 주소만 알려 주면 됩니다. 각자 아래 순서로 자기 키를 넣습니다. 앱 안의 **⚙️ 설정** 화면에 같은 안내와 바로가기 링크가 있습니다.

1. **공공데이터포털 회원가입·로그인** — https://www.data.go.kr
2. **활용신청** — 검색창에 `국립수목원 식물자원` → **산림청 국립수목원_식물자원 조회 서비스**(오픈 API) → 활용신청 (자동승인)
   - 활용목적 예시(설정 화면에서 복사 가능): *초등학교 과학 수업에서 학생이 학교 식물을 사진으로 관찰하고, 국립수목원 식물도감 공식 정보를 조회해 교육과정과 연결된 관찰 기록을 작성하는 비영리 교육용 웹앱에 활용합니다.*
3. **키 복사** — 마이페이지 → 개발계정 (https://www.data.go.kr/iim/api/selectAPIAcountView.do) → 서비스 클릭 → **일반 인증키** 복사
   - Encoding·Decoding 어느 쪽이든, 미리보기 주소를 통째로 붙여 넣어도 앱이 알아서 디코딩 키로 맞춤 (`lib/datakey.ts`)
4. **앱의 ⚙️ 설정 → 붙여 넣기 → [저장하고 연결 확인]** → 초록 글씨가 나오면 끝
5. **AI 키(필수)** — 사진으로 어떤 식물인지 알아보는 핵심 기능. 셋 중 하나를 골라 그 회사 키를 넣기 (없으면 발견 화면의 AI 버튼이 잠기고 설정으로 안내)
   | AI | 키 받는 곳 | 키 모양 | 비용 |
   |---|---|---|---|
   | 제미나이 (구글) | https://aistudio.google.com/apikey | `AQ.…` / `AIza…` | 무료 등급 있음 |
   | 클로드 (Anthropic) | https://platform.claude.com | `sk-ant-…` | 유료(크레딧 충전) |
   | GPT (OpenAI) | https://platform.openai.com/api-keys | `sk-…` / `sk-proj-…` | 유료(크레딧 충전) |
   - 키를 붙여 넣으면 모양을 보고 공급자를 자동으로 맞춤. 세 회사 키를 모두 저장해 두고 골라 쓸 수 있음
   - 제미나이·GPT 모델은 앱이 자동으로 고름: 은퇴(404)·혼잡(5xx)·한도(429)면 다음 모델로 (`lib/server/ai/chain.ts`). `gemini-2.5-flash` 는 새 키로 쓸 수 없어 기본 목록에서 뺌
   - 클로드는 공식 SDK(`@anthropic-ai/sdk`)로 `claude-opus-5-5` 호출(`CLAUDE_MODEL` 로 변경 가능), 구조화 출력(json_schema), 안전 분류기 거절 시 서버 쪽 대체 모델(`fallbacks: "default"`)

자주 막히는 곳 (앱이 결과코드별로 안내함):

| 결과코드 | 뜻 | 해결 |
|---|---|---|
| 20 | 이 서비스 권한 없음 | 다른 API 키가 있어도 **이 서비스는 따로 활용신청** 필요 (키 글자는 같음) |
| 30 | 등록되지 않은 키 | 키를 빠짐없이 복사했는지 확인, 신규 발급 직후면 반영까지 기다림 |
| 31 | 기간 만료 | 마이페이지에서 활용 기간 연장 |
| 22 | 하루 한도 초과 | 개발계정 하루 1,000건. 내일 다시 / 다른 키 |

### 키가 흐르는 길

| 어디에 | 무엇이 | 비고 |
|---|---|---|
| 브라우저 저장소 (`keys`) | 공공데이터포털 키(디코딩으로 정리), 제미나이 키 | "이 기기에 저장"=localStorage, "이번만"=sessionStorage |
| 요청 헤더 | `x-data-key`, `x-ai-provider`, `x-ai-key` | `lib/client/keys.ts` 의 `api()` 가 붙임 |
| 서버 함수 | `lib/server/keys.ts` 의 `getKeys(req)` | 헤더에서 읽어 외부 호출 후 버림, 저장·기록 없음 |
| 서버 환경변수 | `DATA_GO_KR_KEY`, `AI_PROVIDER`, `GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` | `ALLOW_SHARED_KEY=1` 일 때만, 헤더에 키가 없을 때 대신 사용 (강사 시연용) |
| `/api/config` | `{ mock, sharedData, sharedAi, sharedAiProvider }` | 화면이 "키가 꼭 필요한지" 판단. 키 값은 보내지 않음 |

- 공공데이터포털 키가 없으면 `401 NO_DATA_KEY` → 설정 화면으로 이동, 첫 화면에는 "처음 오셨나요?" 안내
- 키가 틀리면 `401 BAD_DATA_KEY` + 결과코드별 안내문 + "키 설정 확인하기" 버튼
- AI 키가 없으면 발견 화면의 AI 버튼이 잠기고 "AI 키가 필요해요 → 설정" 안내 (이름 입력을 주된 길로 쓰지 않음)
- AI 오류는 공급자와 상관없이 같은 종류로 안내: 키(→설정) / 결제·크레딧 / 한도 / 혼잡 / 거절
- 캐시는 검색어·도감번호 기준(키와 무관, 24시간) → 한 반이 같은 식물을 찾아도 호출 1회. 단 '연결 확인'은 캐시를 건너뛰고 실제로 호출
- 학급 기기 일괄 배포: 👩‍🏫 선생님 모드(`/teacher`)의 QR
  - 🔑 키까지 한 번에: 주소 `#k=…` 프래그먼트에 키+학년 (서버로 전송되지 않음). 학급 태블릿·학생 휴대폰용
  - 🔗 앱 주소만: 설정 화면으로 바로. 학생이 각자 자기 키를 넣을 때
  - ⛶ 칠판·TV에 크게 띄우기: 큰 QR + 학생이 할 일 3줄

## 2. 빠른 시작 (개발자·강사)

```bash
npm install
cp .env.example .env.local      # 키 없이 써 보려면 MOCK=1 로
npm run dev                      # http://localhost:3000
```

- 연습 모드(`MOCK=1`): 국립수목원·제미나이를 호출하지 않고 `samples/` 자료로 전체 흐름 시연 (키 불필요)
- 실제 모드(`MOCK=0`): 설정 화면에서 키 입력 → 저장하고 연결 확인
- 받은 키로 실제 응답 확인: `npm run check-api` (또는 `node scripts/check-api.mjs <키>`) → `samples/real_*.xml` 저장
- 테스트: `npm test` · 타입 검사: `npm run typecheck`
- `vercel.json` 의 `regions: ["icn1"]` 로 서버 함수가 서울에서 돈다 → 이 저장소를 Fork 해서 Vercel 에 Import 하면 지역 설정을 따로 바꾸지 않아도 된다 (Hobby 무료 요금제도 지역 하나는 고를 수 있음)

## 3. 전체 흐름

```
① 발견  /            사진 최대 3장(휴대폰 카메라·웹캠·파일·끌어 놓기·붙여넣기) + 장소 + 사전 관찰(잎 모양·잎맥·줄기)
   ↓  POST /api/identify { images: [...] } (고른 AI) → 후보 2~3종 {국명, 학명, 신뢰도, 근거}
② 추정  /            후보 고르기 · 맞는 게 없으면 "사진 더 넣고 다시 묻기" / "AI에게 다시 묻기"
                      (이름 입력은 "이미 이름을 알고 있어요" 접힌 메뉴에만)
   ↓  GET /api/plants/search?q=국명 (국립수목원) → 도감번호  (0건이면 학명 '속명 종소명'으로 재검색)
   ↓  그래도 0건 → /unlisted (아래)
③ 확인  /plant/[no]  GET /api/plants/detail?no= (국립수목원) → 형태·특징·생육환경·분포·유사종…
                      POST /api/explain (고른 AI) → 학년 눈높이: 소개·주제별·항목별 풀이·낱말 풀이·관찰 질문·비교·더 궁금한 점
③' 도감에 없음 /unlisted?name=&sci=
                      POST /api/unlisted (고른 AI) → 학년 눈높이 정보 + 도감에 실렸을 수 있는 다른 이름
                      → 서버가 그 이름으로 국립수목원 도감을 다시 찾음 (lib/server/unlisted.ts)
                        · 다른 이름으로 실려 있으면 → "다른 이름으로 실려 있어요" + 공식 정보로 이동
                        · 없으면 → "국립수목원 식물도감에 정식으로 등록되어 있지 않아요" + AI 정보(공식 아님) + 같은 무리(속) 도감 식물
                        · AI도 모르는 이름이면 → 사진 더 넣고 다시 묻기 안내
📚 교과서 연결        lib/curriculum.ts (규칙) → 학년별 성취기준 원문 + 이어지는 까닭(국립수목원 원문 근거) + 🎯 해 볼 활동
                      (도감에 없는 식물은 장소·내 관찰로만 연결하고, 공식 정보 없이 할 수 있는 activityUnlisted 문장을 씀)
④ 기록  /plant/[no]  일치/불일치/모름 · 관찰 그림(그리기·종이 그림 올리기) · 관찰 질문 답 · 교과서 활동 답 · 새로 알게 된 점 → 나의 도감 저장
📒 나의 도감 /my      카드 / 🗂️ 분류해 보기(관찰 기준·내가 정한 기준) / 📚 교과서별 모아 보기, 인쇄
🔍 검색  /search      이름으로 찾는 작은 도감 (0건이면 "AI에게 알아보기" → /unlisted)
⚙️ 설정  /settings    키 받는 방법·입력·연결 확인·학년·저장 방식
👩‍🏫 교사  /teacher     선생님 모드 3단계 · 학급 QR(키 포함/주소만) · 크게 띄우기 · /curriculum 교육과정 연결표
```

## 4. 교육과정 연결

- 자료: `data/curriculum.json` — 성취기준 원문·해설·고려 사항·탐구 활동은 **교육과정 별책 문장 그대로**, 활동·연결 규칙은 앱 제안
- 기준: 2022 개정 교육과정 (교육부 고시 제2022-33호·국가교육위원회 고시 제2024-3호). **국가교육위원회 고시 제2026-1호(2026.1.21.) 개정분(초등 통합교과 개편)은 미반영** → 1~2학년 연결은 적용 학년도에 맞는지 확인 필요
- 연결 규칙(`match`): 항상 / 공식 정보 항목이 있을 때 / 공식 정보에 낱말이 나올 때 / 찾은 장소 / 줄기 관찰
- AI 쉬운 설명은 연결된 성취기준을 받아 관찰 질문을 맞추고, 해설에서 "다루지 않는다"고 한 내용(예: 3~4학년 '적응', '생물학적 분류 체계')은 쓰지 않도록 지시

| 학년군 | 성취기준 | 연결되는 때 |
|---|---|---|
| 1~2 | [2슬01-04] | 모든 관찰 |
| 3~4 | [4과03-01] 식물 분류 | 모든 관찰 (나의 도감 '분류해 보기'와 연결) |
| 3~4 | [4과03-02] 환경과 생김새 | 생육환경 원문이 있거나 장소를 골랐을 때 |
| 3~4 | [4과04-03] 한살이 유형 | 한해살이·여러해살이 등 낱말, 나무줄기 관찰 |
| 3~4 | [4과04-02] 자라는 조건 | 햇빛·그늘·습기 등 낱말, 교실 화분 |
| 3~4 | [4과14-01]·[4과14-02]·[4과14-03] 생물과 환경 | 바깥 장소 / 곤충·열매 등 / 보호 방안·멸종 등 |
| 3~4 | [4과03-03] 생활용품 설계 | 이용 방안, 가시·갈고리 등 |
| 5~6 | [6과11-02]·[6과11-03] 식물의 구조와 기능 | 모든 관찰 |
| 5~6 | [6실04-07]·[6실04-08] 실과 | 이용 방안·식용 등 / 교실 화분·화단·재배 등 |

## 5. 국립수목원 API

기본 주소 `https://apis.data.go.kr/1400119/PlantResource` · 응답 XML

| 오퍼레이션 | 요청 변수 | 응답 핵심 항목 |
|---|---|---|
| `GET /plantPilbkSearch` | `serviceKey`, `pageNo`, `numOfRows`, `reqSearchWrd`(국명/학명) | `plantPilbkNo`, `plantGnrlNm`, `plantSpecsScnm`, `familyKorNm`, `genusKorNm`, `totalCount` |
| `GET /plantPilbkInfo` | `serviceKey`, `reqPlantPilbkNo` | `shpe` 형태, `spft` 특징, `grwEvrntDesc` 생육환경, `dstrb` 분포, `osDstrb`, `rrngType`, `rrngGubun`, `smlrPlntDesc` 유사종, `useMthdDesc`, `prtcPlnDesc`, `orplcNm`, `inductionDesc`, `engNm` |

- 응답에 이미지 항목 없음 → 카드 사진은 학생이 찍은 사진
- 결과코드 `00` 정상, `03` 데이터 없음, 인증 오류는 `OpenAPI_ServiceResponse > cmmMsgHeader > returnReasonCode`. XML이 아닌 `Unauthorized` 같은 응답도 키 문제로 처리
- 이용허락: 출처표시·상업적 이용금지·변경금지 → 원문은 수정 없이 표시, 교과서 연결의 근거 문장도 원문 한 문장을 그대로 인용, AI 재구성 글은 별도 탭

## 6. 배포 (Vercel 등)

1. 저장소를 Vercel 에서 가져오기 (Next.js 자동 인식)
2. 환경변수: 여러 사람이 각자 키를 넣는 배포본은 `MOCK=0`, `ALLOW_SHARED_KEY=0` 만 (서버에 키 없음). 강사 시연본은 `ALLOW_SHARED_KEY=1` + 키. `GEMINI_MODEL` 은 비워 두기를 권장 (자동 선택)
   - 지금 배포본: https://plant-explorer-delta.vercel.app (서버 지역 서울 icn1, 이 브랜치에 올리면 자동 배포)
3. 배포 주소는 **HTTPS** → 휴대폰 카메라·컴퓨터 웹캠 모두 사용 가능. QR 코드로 주소 배포
4. 같은 와이파이의 휴대폰에서 `http://내컴퓨터IP:3000` 으로 시험할 때: 휴대폰 카메라(파일 입력)는 되지만, 웹캠 창은 https 에서만 열림
